# Enterprise Schema Mapping Document: SQL Server ➔ Canonical ➔ PostgreSQL

## 1. Executive Summary

This document provides a comprehensive, field-by-field cross-reference across all **26 enterprise entities** and **224 columns** in the Enterprise ERP POC.

The migration follows an explicit 3-layer architecture:
```
Source SQL Server Column ──▶ Canonical Model Attribute ──▶ Target PostgreSQL Column
```

## 2. Global Type Mapping Reference

| SQL Server Type | Canonical Abstract Type | PostgreSQL Native Type | Coercion Rule / Semantic |
| :--- | :--- | :--- | :--- |
| `INT IDENTITY(1,1)` | `INTEGER_32` | `INTEGER GENERATED BY DEFAULT AS IDENTITY` | Sequence synchronized after ETL |
| `BIGINT IDENTITY(1,1)` | `INTEGER_64` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | Sequence synchronized after ETL |
| `TINYINT` | `SMALL_INT` | `SMALLINT` | Promoted to 16-bit signed integer |
| `BIT` | `BOOLEAN` | `BOOLEAN` | `1/0` converted to Python `True/False` |
| `DECIMAL(p,s)` | `DECIMAL` | `NUMERIC(p,s)` | Exact numeric representation preserved |
| `NVARCHAR(n)` | `VARIABLE_STRING` | `VARCHAR(n)` | Character length preserved |
| `NVARCHAR(MAX)` | `LONG_TEXT` | `TEXT` | Unbounded textual content |
| `DATETIME2(7)` | `TIMESTAMP_TZ` | `TIMESTAMPTZ` | Microsecond UTC timestamp |
| `DATE` | `DATE` | `DATE` | Calendar date |
| `UNIQUEIDENTIFIER` | `UUID` | `UUID` | UUID string representation |
| `XML` | `XML` | `XML` | Native XML structure |
